# Overview

This repository contains the code for ACL2025 paper **Evaluating the Evaluation of Diversity in Commonsense Generation**

It includes generating candidate sets and evaluating diversity metrics, as well as the experimental data used in our paper.

## Data

All experimental data used in our paper are stored in the `data` folder, organized as follows:

- **`data/High_Quality_Diversity_Data`**  
  This directory contains the final high-quality annotated sentence sets for the three Generative Commonsense Reasoning (GCR) datasets used in our paper: **CommonGen, ComVE, and DimonGen**. Each file includes the generated sentences and their corresponding LLM diversity scores, ready for use in your own tasks.

- **`data/quality_evaluation`**  
  Contains the evaluation results generated by the CommonGen-EVAL quality evaluation script.

## LLM Scorer Template
You can adapt our LLM-based diversity scorer for your own evaluation tasks. The detailed prompt, which is designed to be task-independent, can be found in `templates/template.txt`.


## Code

The scripts for generating candidate sets and evaluating diversity metrics are located in the `code` folder. Before you run the code, you need to install the necessary nlg-eval package from https://github.com/Maluuba/nlg-eval.

- **`llm_generator.py`**  
  Run this script to regenerate candidate sets.

- **`llm_evalutator.py`**  
  Run this script to reevaluate the data.
